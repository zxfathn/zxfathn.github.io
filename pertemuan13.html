Pengenalan Web - Pertemuan 13

Penggunaan Tag div dalam HTML

Div digunakan untuk mengelompokkan elemen-elemen dalam satu bagian atau bagian tertentu di halaman web, sehingga lebih mudah untuk memberikan style CSS. Berikut adalah contoh penggunaan tag div:

<div style="background-color:#9370DB;color:white;padding:30px;font-size:20px;">
    <h2>HTML</h2>
    <p>Pemrograman web yang paling dasar adalah HTML.</p>
</div>

Perbedaan antara div dan span

Div digunakan untuk mengelompokkan elemen dalam blok, sementara span digunakan untuk mengelompokkan elemen dalam baris, tanpa mempengaruhi layout halaman. Span adalah elemen inline, sedangkan div adalah elemen blok.

Perbedaan antara Class dan ID

Class digunakan untuk memberi nama pada sekumpulan elemen dan bisa dipanggil berkali-kali dalam HTML. Sedangkan ID digunakan untuk memberi nama pada elemen yang unik dan hanya digunakan satu kali di halaman web.

<style>
    .class-example {
        font-size: 20px;
        font-weight: bold;
        color: red;
    }

    #id-example {
        font-size: 22px;
        color: green;
    }
</style>
<div class="class-example">This is a class example</div>
<div id="id-example">This is an ID example</div>

Latihan Penggunaan Class dan ID

Buat dua elemen div dengan class dan ID, dan atur gaya menggunakan CSS:

<div class="class-example">This is a class example</div>
<div id="id-example">This is an ID example</div>
