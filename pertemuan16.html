Tipe Data dan Operator di JavaScript

Contoh penggunaan Tipe Data dan Operator dalam JavaScript

Contoh Tipe Data dalam JavaScript

var integer = 100; // Tipe data numerik integer
var floatingPoint = 3.14159; // Tipe data numerik floating point
var string = "Hello, JavaScript!"; // Tipe data string
var boolean = true; // Tipe data boolean
var notDefined = null; // Tipe data null

Contoh Operator dalam JavaScript

var a = 5;
var b = 10;
var sum = a + b; // Operator Aritmatika
var comparison = (a < b); // Operator Pembanding
var logical = (a > 3 && b < 15); // Operator Logika

var name = "Java" + "Script"; // Operator String

Operasi Aritmatika

Berikut adalah contoh operasi aritmatika menggunakan operator `+`, `-`, `*`, dan `/`:

var x = 10;
var y = 5;
var resultAdd = x + y; // Penjumlahan
var resultSub = x - y; // Pengurangan
var resultMul = x * y; // Perkalian
var resultDiv = x / y; // Pembagian

Operasi Pembanding dan Logika

Contoh penggunaan operator pembanding (`==`, `!=`, `>`, `<`) dan logika (`&&`, `||`):

var isGreaterThan = (x > y); // Pembanding lebih besar
var isEqual = (x == y); // Pembanding sama dengan
var isAnd = (x > 3 && y < 10); // Operator logika AND
var isOr = (x < 3 || y > 1); // Operator logika OR

Latihan Penggunaan Operator

Berikut adalah contoh latihan untuk menggunakan operator dalam JavaScript:

var num1 = 15;
var num2 = 25;
var result = num1 * num2;
alert("Hasil perkalian adalah: " + result); // Menampilkan hasil perkalian dalam alert
