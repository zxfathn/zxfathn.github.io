Menampilkan Gambar di HTML

Untuk menampilkan gambar di halaman web, kita menggunakan tag <img>. Berikut adalah contoh penggunaan gambar:

Gambar ini diambil dari sumber URL yang diberikan dan ditampilkan menggunakan tag <img> dengan atribut src sebagai sumber gambar dan alt untuk teks alternatifnya.

Contoh Source Code:

<img src="https://ella.janitorai.com/bot-avatars/5K-CX1Xs29BMqgYlB8Vbb.webp" alt="Avatar Gambar" />

Menampilkan Suara di HTML

Untuk menambahkan suara ke halaman web, kita menggunakan tag <embed>. Berikut adalah contoh penggunaan untuk menampilkan suara:

Gantilah URL sumber audio pada atribut src dengan file suara yang Anda miliki.

Contoh Source Code:

<embed src="https://www.soundhelix.com/examples/mp3/SoundHelix-Song-1.mp3" loop="true" autoplay="false" width="300" height="60" />

Menampilkan Video di HTML

Untuk menambahkan video ke halaman web, kita menggunakan tag <video>. Berikut adalah contoh penggunaan tag video untuk menampilkan video:

Dengan menggunakan tag <video>, kita dapat mengontrol video melalui atribut controls.

Contoh Source Code:

<video width="400" controls>
    <source src="https://www.w3schools.com/html/mov_bbb.mp4" type="video/mp4">
    <source src="https://www.w3schools.com/html/movie.ogg" type="video/ogg">
    Browser anda tidak mendukung video pada HTML5.
</video>
