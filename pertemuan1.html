Penggunaan Frameset dalam HTML - Pertemuan 9

Pengenalan Elemen Frame pada HTML

Elemen <frameset> digunakan untuk membagi tampilan layar menjadi beberapa bagian berdasarkan baris atau kolom.

Contoh penggunaan elemen <frameset>:

<frameset rows="25%, 65%, 10%">
    <frame src="header.html" noresize>
    <frameset cols="15%, 85%">
        <frame src="menu.html">
        <frame src="home.html" name="kanan">
    </frameset>
    <frame src="footer.html" noresize scrolling="no">
</frameset>

Contoh Layout Frameset

Layout dengan menggunakan frameset dapat dibagi menjadi beberapa jenis: vertikal, campuran, atau menggunakan persentase untuk ukuran frame.

Contoh frameset campuran:

<html>
<head>
    <title>Frame Campuran</title>
</head>
<frameset rows="25%, *">
    <frame name="frame1" src="frame1.html" scrolling="no" noresize>
    <frameset cols="25%, *">
        <frame name="frame2" src="frame2.html">
        <frame name="frame3" src="frame3.html" scrolling="auto">
    </frameset>
    <noframes>
        <body>Maaf, browser Anda tidak mendukung penggunaan frame.</body>
    </noframes>
</frameset>
</html>

Latihan Membuat Frame

Latihan ini mencakup pembuatan beberapa halaman HTML yang dihubungkan dengan frameset:

index.html

<html>
<head>
    <title>Membuat Frame berdasarkan Baris dan Kolom</title>
</head>
<frameset rows="25%, 65%, 10%">
    <frame src="header.html" noresize>
    <frameset cols="15%, 85%">
        <frame src="menu.html">
        <frame src="home.html" name="kanan">
    </frameset>
    <frame src="footer.html" noresize scrolling="no">
</frameset>
</html>

menu.html

<html>
<head>
    <title>Menu dengan Hyperlink</title>
</head>
<body>
    <font color="navy" size="4">Menu</font>
    <ul type="square">
        <li><a href="home.html" target="kanan">Home</a></li>
        <li><a href="profil.html" target="kanan">Profil</a></li>
        <li><a href="galery.html" target="kanan">Gallery</a></li>
        <li><a href="kontak.html" target="kanan">Kontak</a></li>
    </ul>
</body>
</html>
