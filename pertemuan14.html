Pengenalan JavaScript - Pertemuan 14

Pengenalan JavaScript

JavaScript pertama kali diperkenalkan oleh Netscape pada tahun 1995, dengan nama awal LiveScript. JavaScript berfungsi untuk memberikan interaktivitas dalam halaman web, dan dapat dijalankan langsung di browser.

Perbedaan JavaScript dan Java

Walaupun JavaScript dan Java memiliki nama yang serupa, keduanya memiliki perbedaan besar. JavaScript digunakan untuk menambahkan interaktivitas pada halaman web, sementara Java adalah bahasa pemrograman yang digunakan untuk pengembangan aplikasi yang lebih besar dan lebih kompleks.

Variabel dalam JavaScript

Dalam JavaScript, variabel digunakan untuk menyimpan data sementara dalam memori komputer. Variabel dapat dideklarasikan dengan kata kunci var, let, atau const. Berikut adalah cara mendeklarasikan dan menggunakan variabel:

<script type="text/javascript">
    var myFirstVariable;
    myFirstVariable = "Hello";
    alert(myFirstVariable);
    myFirstVariable = 54321;
    alert(myFirstVariable);

    var string1 = "Hai, bagaimana kabarmu?";
    var string2 = "Goodbye";
    string2 = string1;
    alert(string2);

    string1 = "Sekarang berbeda";
    alert(string1);
    alert(string2);
</script>

Latihan

Berikut adalah contoh sederhana yang akan menampilkan pesan menggunakan variabel dalam JavaScript:

<html>
    <head></head>
    <body>
        <script language="JavaScript" type="text/javascript">
            var message = "Selamat datang di belajar JavaScript!";
            alert(message);
        </script>
    </body>
</html>
