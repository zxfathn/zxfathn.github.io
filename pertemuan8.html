Rangkuman Materi: Fungsi dan Array di JavaScript

Fungsi (Function):
Fungsi adalah blok kode yang dapat digunakan kembali untuk melakukan tugas tertentu. Fungsi di JavaScript dapat menerima parameter dan mengembalikan nilai dengan menggunakan kata kunci `return`.

Array:
Array adalah struktur data yang menyimpan kumpulan nilai dalam satu variabel. Setiap elemen di dalam array dapat diakses menggunakan indeks yang dimulai dari 0.

Contoh penggunaan fungsi dan array di JavaScript:


function greet(name) {
    return "Hello, " + name;
}

var fruits = ["Apple", "Banana", "Cherry"];
console.log(greet(fruits[1])); // Output: Hello, Banana
