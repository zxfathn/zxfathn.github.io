Pengenalan Web - Pertemuan 11

Penggunaan Atribut CSS untuk Font

Berikut adalah beberapa atribut yang digunakan untuk pengaturan font dalam CSS:

font-size: xx-large;
font-family: "Arial", sans-serif;
font-weight: bold;
font-style: italic;

Contoh Penggunaan Font di CSS

Contoh penggunaan pengaturan font pada elemen h1:

h1 {
    font-family: "Tahoma", sans-serif;
    font-size: 25px;
    font-weight: bold;
    font-style: italic;
}

Pengaturan Teks

Gunakan text-align untuk mengatur perataan teks:

text-align: left; /* Mengatur teks rata kiri */
text-align: center; /* Mengatur teks rata tengah */
text-align: right; /* Mengatur teks rata kanan */
text-align: justify; /* Mengatur teks agar rata kanan-kiri */

Pengaturan Margin

Atribut margin digunakan untuk memberikan jarak di sekitar elemen:

margin-left: 20px;
margin-right: 15px;
margin-top: 10px;
margin-bottom: 5px;

Contoh Posisi Gambar dengan CSS

Berikut adalah contoh pengaturan posisi gambar dengan CSS menggunakan float:

Posisi gambar di bagian kanan teks.

<img src="image.jpg" style="float:right;width:50px;height:50px;">

Pengaturan Warna dalam CSS

Berikut adalah cara mendefinisikan warna teks dan latar belakang:

color: red; /* Warna teks merah */
background-color: #ffcc00; /* Warna latar belakang kuning */

Latihan Penggunaan CSS

Untuk mengatur tampilan website Anda, coba buatlah beberapa file CSS eksternal dan hubungkan dengan file HTML Anda menggunakan tag <link> atau gunakan tag style dalam elemen <head>.

<link rel="stylesheet" href="styles.css">
