Tag HTML untuk Format Teks

HTML menggunakan tag untuk menandai elemen-elemen di halaman web. Berikut adalah beberapa tag untuk format teks:

  • <b>: Menebalkan teks
  • <strong>: Menebalkan teks dengan makna semantik
  • <i>: Memiringkan teks
  • <em>: Menekankan teks
  • <small>: Memperkecil ukuran teks
  • <big>: Memperbesar ukuran teks
  • <sub>: Menampilkan teks sebagai subscript
  • <sup>: Menampilkan teks sebagai superscript
  • <u>: Menambahkan garis bawah pada teks
  • <s>: Mencoret teks

Contoh Penggunaan Tag HTML

Berikut adalah contoh penggunaan tag HTML untuk memformat teks:

<b>Teks Tebal</b>
<strong>Teks Penting</strong>
<i>Teks Miring</i>
<em>Teks yang Ditekankan</em>
<small>Teks Kecil</small>
<big>Teks Besar</big>
<sub>H<sub>2</sub>O</sub>
<sup>E=mc<sup>2</sup></sup>

Karakter Khusus dalam HTML

HTML menggunakan entitas untuk menampilkan karakter khusus seperti simbol, tanda kutip, atau karakter lainnya. Berikut adalah beberapa entitas umum:

  • © untuk © (Copyright)
  • ® untuk ® (Registered Trademark)
  • & untuk & (Ampersand)
  • < untuk < (Less Than)
  • > untuk > (Greater Than)
  • " untuk " (Double Quote)
  •   untuk (Non-breaking Space)
