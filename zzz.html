Elemen DIV HTML

1. Pengertian <div>

Elemen <div> adalah elemen HTML berbentuk block-level yang digunakan untuk:

  • Mengelompokkan elemen-elemen HTML ke dalam satu blok.
  • Membuat struktur halaman (layout).
  • Menjadi wadah untuk CSS dan JavaScript.

2. Contoh dasar <div>

<div>Ini adalah sebuah div sederhana.</div>

3. Contoh DIV dengan Styling

<div style="background:#7c53c9; color:white; padding:15px; border-radius:10px;">
  Contoh div dengan style.
</div>

4. Contoh DIV untuk Struktur Halaman

<div id="header">Header</div>
<div id="menu">Menu</div>
<div id="content">Konten</div>
<div id="footer">Footer</div>
