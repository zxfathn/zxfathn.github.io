Pengenalan Web - Pertemuan 2

Tag HTML Dasar

HTML menggunakan tag untuk menandai elemen-elemen di halaman web. Tag HTML terdiri dari tag pembuka dan tag penutup. Struktur dasar penulisan tag HTML adalah seperti berikut:

<nama_tag>konten</nama_tag>

Contoh penggunaan tag HTML:

  • <h1>...</h1> - Heading 1, digunakan untuk judul utama.
  • <p>...</p> - Paragraf, digunakan untuk teks paragraf.
  • <br> - Line break, digunakan untuk membuat baris baru.
  • <hr> - Horizontal rule, digunakan untuk membuat garis horizontal.
  • <pre>...</pre> - Preformatted text, menampilkan teks sesuai dengan format aslinya, termasuk spasi dan baris baru.

Bagian Head dalam HTML

Bagian <head> dalam dokumen HTML berfungsi untuk menyimpan informasi meta tentang halaman web, seperti judul halaman, metadata, dan link ke file eksternal seperti CSS dan JavaScript. Contoh:

<head>
    <title>Judul Halaman</title>
    <meta name="description" content="Deskripsi halaman web">
    <link rel="stylesheet" href="styles.css">
</head>

Contoh penggunaan <meta> tag untuk menambahkan deskripsi dan pengaturan pencarian:

  • <meta name="description"> - Menyediakan deskripsi singkat tentang halaman web.
  • <meta name="keywords"> - Menyediakan kata kunci untuk mesin pencari.

Bagian Body dalam HTML

Bagian <body> berisi semua konten yang akan ditampilkan di halaman web. Elemen-elemen seperti teks, gambar, dan form diletakkan di dalam <body>. Contoh:

<body>
    <h1>Selamat datang di website kami!</h1>
    <p>Ini adalah halaman pertama saya.</p>
</body>

Contoh Penggunaan Tag HTML

Berikut adalah contoh penggunaan tag HTML dasar pada sebuah halaman:

<html>
    <head>
        <title>Website Film Terkenal</title>
    </head>
    <body>
        <h1>Selamat datang pada website film terkenal</h1>
        <p>Website ini memberikan informasi tentang film-film terkenal.</p>
        <br>
        <hr>
        <pre>Teks ini akan ditampilkan dengan format yang sama</pre>
    </body>
</html>
