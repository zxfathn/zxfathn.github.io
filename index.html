Form di HTML digunakan untuk mengumpulkan data dari pengguna. Elemen form terdiri dari berbagai input seperti teks, email, password, radio buttons, checkbox, dan banyak lagi. Berikut adalah beberapa contoh penggunaannya.

1. Contoh Dasar Form HTML

                <form action="/submit" method="POST">
                    <input type="text" name="username" placeholder="Username">
                    <input type="password" name="password" placeholder="Password">
                    <button type="submit">Submit</button>
                </form>

2. Penggunaan Input Type

HTML menyediakan berbagai jenis input yang dapat digunakan di dalam form:

  • type="text": Digunakan untuk input teks biasa.
  • type="email": Digunakan untuk input email.
  • type="password": Digunakan untuk input kata sandi.
  • type="checkbox": Digunakan untuk pilihan yang bisa dicentang.
  • type="radio": Digunakan untuk memilih salah satu opsi dari beberapa pilihan.
  • select: Digunakan untuk memilih dari dropdown list.

3. Menangani Pengiriman Form

Form dapat dikirim menggunakan berbagai metode seperti POST atau GET. Misalnya, ketika form disubmit, data akan dikirim ke server untuk diproses.

Contoh Penggunaan Form Dengan POST:

                <form action="/submit" method="POST">
                    <input type="text" name="username" placeholder="Username">
                    <input type="password" name="password" placeholder="Password">
                    <button type="submit">Submit</button>
                </form>
