Rangkuman Materi: Membuat Halaman Login dengan HTML, CSS, dan JavaScript

Halaman login adalah bagian yang sangat penting dalam setiap aplikasi web. Di sini, kita akan membuat halaman login sederhana menggunakan **HTML**, **CSS**, dan **JavaScript**.

Langkah-langkah Membuat Halaman Login:

  • HTML: Membuat struktur form untuk input pengguna.
  • CSS: Menata halaman agar tampak menarik, menggunakan background, form styling, dan responsivitas.
  • JavaScript: Menambahkan fungsi validasi untuk mengecek username dan password, serta membatasi percobaan login.

Contoh HTML untuk Login Form:


<form onsubmit="return cekLogin()">
    <input type="text" id="username" placeholder="Username" required>
    <input type="password" id="password" placeholder="Password" required>
    <button type="submit">Login</button>
</form>

Contoh CSS untuk Menata Form Login:


.login-form {
    background-color: rgba(0, 0, 0, 0.7);
    border-radius: 10px;
    padding: 30px;
    box-shadow: 0 4px 8px rgba(0, 0, 0, 0.5);
    width: 100%;
    max-width: 400px;
    margin: auto;
}
.login-form input {
    width: 100%;
    padding: 10px;
    margin-top: 10px;
    border-radius: 8px;
    border: 1px solid #ccc;
    font-size: 14px;
}

Contoh JavaScript untuk Validasi Login:


function cekLogin() {
    let username = document.getElementById("username").value;
    let password = document.getElementById("password").value;

    if (username === "admin" && password === "12345") {
        alert("Login Berhasil!");
        return true;
    } else {
        alert("Username atau password salah!");
        return false;
    }
}
