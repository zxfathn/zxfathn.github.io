Pengenalan Web - Pertemuan 6

Ordered List (List dengan Penomoran)

Tag <ol> digunakan untuk membuat daftar dengan penomoran. Atribut type bisa digunakan untuk memilih jenis penomoran yang digunakan, seperti I, A, 1, dan sebagainya.

<ol type="A">
    <li>Jakarta</li>
    <li>Bandung</li>
    <li>Surabaya</li>
</ol>

Unordered List (List Tanpa Penomoran)

Tag <ul> digunakan untuk membuat daftar tanpa penomoran. Anda bisa memilih bullet yang berbeda dengan atribut type.

<ul type="circle">
    <li>Fortran</li>
    <li>Cobol</li>
    <li>Java</li>
</ul>

Menu List (Daftar Menu)

Tag <menu> digunakan untuk menampilkan daftar tanpa penomoran atau bullet. Setiap item dalam daftar menggunakan tag <li>.

<menu>
    <li>Pasca Sarjana</li>
    <li>Sarjana</li>
    <li>Diploma III</li>
</menu>

Definition List (Daftar Definisi)

Tag <dl> digunakan untuk membuat daftar definisi. Tag <dt> digunakan untuk mendefinisikan istilah, dan <dd> digunakan untuk mendefinisikan deskripsi atau penjelasan dari istilah tersebut.

<dl>
    <dt>Website</dt>
    <dd>Website adalah laman yang ditampilkan oleh browser yang digunakan untuk menampilkan informasi.</dd>
</dl>
