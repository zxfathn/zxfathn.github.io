## 📖 About

ZXFathan Academy is a cybersecurity education platform designed to help beginners learn cyber security through interactive challenges, learning modules, quizzes, achievements, and ranking systems.

Unlike traditional learning platforms, ZXFathan Academy uses a gamification approach where users earn XP, level up, unlock badges, and complete cybersecurity missions while learning.
