Pengenalan Web - Pertemuan 10

Penggunaan Iframe

Tag <iframe> digunakan untuk menyematkan halaman web lain dalam halaman web kita. Ini memungkinkan Anda menampilkan konten dari situs lain di dalam halaman yang sedang aktif.

<iframe src="https://example.com" width="600" height="400">
    <p>Jika browser Anda tidak mendukung iframe, konten ini akan tampil.</p>
</iframe>

Contoh Penggunaan Iframe

Berikut adalah contoh penggunaan iframe untuk menyematkan halaman web:

Contoh Source Code:

<iframe src="https://indarnirmala.wordpress.com" frameborder="1" width="100%" height="300">
    <p>Tulisan ini akan tampil jika browser tidak support Iframe</p>
</iframe>

Iframe dengan CSS Styling

Anda bisa mengatur ukuran iframe menggunakan CSS, misalnya dengan mengatur tinggi dan lebar elemen tersebut.

Contoh Source Code:

<iframe src="https://example.com" style="height: 275px; width: 325px;"></iframe>

Latihan Penggunaan Iframe

Buat halaman baru dengan menggunakan iframe untuk menampilkan halaman lain, dan sesuaikan ukuran iframe menggunakan CSS.

Contoh Source Code:

<html>
    <head>
        <title>Penggunaan Iframe</title>
    </head>
    <body>
        <h2>Implementasi Penggunaan Iframe</h2>
        <p>Anda dapat mensetting tinggi dan lebar dari Iframe dengan menggunakan CSS</p>
        <iframe src="iframe2.html" style="height: 275px; width: 325px;"></iframe>
    </body>
</html>
