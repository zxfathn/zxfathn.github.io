Struktur Tabel dengan Frameset

HTML menyediakan elemen frameset untuk mengatur tata letak dengan membagi layar menjadi beberapa bagian berdasarkan baris dan kolom.

Struktur penulisan frameset adalah sebagai berikut:

<html>
    <head>--- bagian head ---</head>
    <frameset>--- bagian frame ---</frameset>
</html>

Contoh Layout Frame Berdasarkan Baris

Contoh layout dengan menggunakan frameset untuk membagi layar menjadi beberapa bagian dalam baris:

<frameset rows="25%,65%,10%">
    <frame src="header.html" noresize>
    <frameset cols="15%, 85%">
        <frame src="menu.html">
        <frame src="home.html" name="kanan">
    </frameset>
    <frame src="footer.html" noresize scrolling="no">
</frameset>

Contoh Layout Frame Campuran

Contoh layout frame campuran dengan baris dan kolom menggunakan frameset:

<html>
    <head>
        <title>Frame Campuran</title>
    </head>
    <frameset rows="25%, *">
        <frame name="frame1" src="frame1.html" scrolling="no" noresize>
        <frameset cols="25%, *">
            <frame name="frame2" src="frame2.html">
            <frame name="frame3" src="frame3.html" scrolling="auto">
        </frameset>
    </frameset>
    <noframes>
        <body>
            Maaf, browser Anda tidak mendukung penggunaan frame.
        </body>
    </noframes>
</html>

Latihan

Buat beberapa file HTML di dalam satu folder untuk membuat halaman website dengan berbagai file seperti index.html, menu.html, home.html, profil.html, galery.html, dan kontak.html.

Berikut adalah contoh script untuk file index.html:

<html>
    <head>
        <title>Membuat Frame Berdasarkan Baris dan Kolom</title>
    </head>
    <frameset rows="25%,65%,10%">
        <frame src="header.html" noresize>
        <frameset cols="15%, 85%">
            <frame src="menu.html">
            <frame src="home.html" name="kanan">
        </frameset>
        <frame src="footer.html" noresize scrolling="no">
    </frameset>
</html>
