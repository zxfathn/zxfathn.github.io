Penggunaan Class dalam CSS

Class digunakan untuk memberikan nama kepada sekelompok gaya yang bisa diterapkan pada elemen tertentu. Berikut adalah contoh penggunaan class dalam CSS:

p.htebal {
    font-family: "Tahoma", sans-serif;
    font-weight: bold;
    color: blue;
    font-size: 16pt;
    text-indent: 40pt;
}
p.hmiring {
    font-family: "Tahoma", sans-serif;
    font-weight: italic;
    color: red;
    font-size: 18pt;
    text-indent: 55pt;
}

Penggunaan Align pada CSS

CSS memungkinkan kita untuk mengatur perataan teks dengan menggunakan text-align. Berikut adalah contohnya:

h1 {
    text-align: center;
}

p.date {
    text-align: right;
}

p.main {
    text-align: justify;
    font-size: 125%;
    color: red;
}
